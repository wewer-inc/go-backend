# Security Policy

## Scope

**In scope:** vulnerabilities in the boilerplate patterns themselves — the auth middleware, JWT handling, rate limiting, config loading, or any other pattern this repository provides.

**Out of scope:** vulnerabilities in applications built using this boilerplate. Those are the responsibility of the teams that built them.

## Supported Versions

Only the latest release of this boilerplate receives fixes.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security matters.**

Email **hello@wewer.io** with:

- A description of the issue and its potential impact
- Steps to reproduce or a proof-of-concept (if applicable)
- Any suggested remediation

We will acknowledge receipt within **72 hours**. Confirmed issues will be resolved at our discretion based on severity and complexity — we do not commit to fixed timelines.

We appreciate responsible disclosure and will credit reporters in the release notes unless you prefer to remain anonymous.
